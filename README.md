# দেশি মুরগি পালন মাস্টার একাডেমি

বাংলাদেশের দেশি মুরগি খামারিদের জন্য বাংলা ভাষার অফলাইন Android প্রশিক্ষণ ও ব্যবস্থাপনা অ্যাপ।

## অ্যাপের সুবিধা
- দেশি মুরগির জাত ও বাচ্চা নির্বাচন
- ঘর, উঠান, নিরাপদ বিচরণ ও শিকারি প্রাণী থেকে সুরক্ষা
- বাচ্চা পালন ও ব্রুডিং
- বয়সভিত্তিক খাদ্য, পানি ও পুষ্টি
- ডিম সংগ্রহ, তা দেওয়া ও বাচ্চা ফোটানো
- স্বাস্থ্য পর্যবেক্ষণ, বায়োসিকিউরিটি এবং টিকা সম্পর্কে নিরাপদ নির্দেশনা
- প্রজনন, উৎপাদন রেকর্ড ও ব্যবসা ব্যবস্থাপনা
- পাঠ অনুসন্ধান, লাভ-ক্ষতি ক্যালকুলেটর, খাবার হিসাব ও ফোনে সংরক্ষিত দৈনিক ডায়েরি

## Android APK তৈরি
প্রয়োজন: JDK 17 এবং Android SDK।
```bash
gradle assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`

GitHub Actions-এ `main` শাখায় push হলেই debug APK তৈরি হবে। Repository-এর **Actions** ট্যাবে সর্বশেষ সফল workflow run খুলে **Artifacts** থেকে APK ZIP ডাউনলোড করুন।

## স্বাস্থ্য ও নিরাপত্তা
এই অ্যাপের বিষয়বস্তু শিক্ষামূলক; এটি রোগ নির্ণয়, চিকিৎসা, ওষুধ বা টিকার বিকল্প নয়। টিকা-সূচি, রোগ, ওষুধ ও মাত্রা স্থানীয় রোগ পরিস্থিতি, পাখির বয়স এবং ভ্যাকসিন/ওষুধের লেবেল অনুযায়ী উপজেলা প্রাণিসম্পদ কর্মকর্তা বা নিবন্ধিত ভেটেরিনারিয়ানের কাছ থেকে নিশ্চিত করুন। নিজের সিদ্ধান্তে অ্যান্টিবায়োটিক ব্যবহার করবেন না।

খাদ্য গ্রহণ, বৃদ্ধি, ডিম উৎপাদন ও বাজারদর জাত, বয়স, আবহাওয়া, ব্যবস্থাপনা ও এলাকার ওপর নির্ভরশীল। ক্যালকুলেটরে নিজের খামারের প্রকৃত সংখ্যা ও দাম লিখুন।
